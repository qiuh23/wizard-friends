# 玩法与牌桌审查 · 2026-10-29

本次以个人仓库 `main` 的 `6789502` 为基线，核对已提供的全部选项与人数。基本规则来自 [AMIGO 官方规则第 1–2 页](https://blog.amigo-spiele.de/content/ap/rule/06900-GB-AmigoRule.pdf)；历史变体与本项目已接受的改规则定以 [D-001](dev-memory/DECISIONS.md#d-001)、[D-006](dev-memory/DECISIONS.md#d-006)、[D-013](dev-memory/DECISIONS.md#d-013) 为准。没有引入未提供的新玩法。

## 规则核对

| 项目 | 当前要求与验证 |
| --- | --- |
| 标准牌库 | 四色 1–13，加四张 W、四张 J，共 60 张。3–6 人，首轮一张、逐轮增加，完整局分别为 20、15、12、10 轮。 |
| 跟花 | 首张数字牌确立跟花要求；手中有该色数字牌时，其他数字牌与异色主牌均不可出。W/J 随时可出，后出的 W 不解除已经确立的要求。 |
| 特殊首攻 | W 首攻，或若干 J 后先出现 W，本墩自由出牌。若干 J 后先出现数字牌，则从该牌起跟花。没有所需颜色时自由出牌。 |
| 判胜 | 第一张 W；否则最大主牌；否则首攻色最大数字。全 J 时第一张 J 获胜。赢家下墩先出。 |
| 主牌 | 翻到数字牌用该色，W 由庄家选色，J 或没有余牌则无主牌。无主牌仍须跟花。 |
| 座次 | 公开预估与首墩从庄家左手边开始；每轮庄家顺时针轮换，之后每墩由赢家首攻。 |
| 公开预估／加减预估 | 依座次各提交一次，数值为 0–本轮墩数。加减预估只限制最后一人的选择，保证合计不等于本轮墩数。 |
| 隐藏预估 | 可独立提交；全员提交前不公开他人的数字，进入出牌时一起公开。 |
| 秘密数字 | 可独立提交；本轮中途及墩末不公开他人的数字，到轮末再公开。日志、计分历史和观战视图同样过滤。 |
| 先见之明 | 按项目已接受的约定，开启后每轮预估时看他人的整手牌、隐藏自己的牌，全员提交后恢复正常；单色也如此。观众始终不能看手牌，机器人只读其权限视图。此处是本项目约定，不声称等同于原版首轮玩法。 |
| 单色牌库 | 限 3–4 人，每人独占一色 1–13、一个 W 和一个 J。每轮重洗完整个人牌库，第 1–12 轮各发 4–15 张。无主牌、不跟花色；数字直接比大小，同数先出胜。特殊牌和计分沿用基本规则。 |
| 快速局 | 五轮；标准发 1–5 张，单色发 4–8 张。 |
| 计分与整局 | 猜中得 20 + 10 × 实赢；猜错扣 10 × 绝对偏差。按累计最高分判胜，同分共同获胜。大厅选项整局固定，续局可重新选择。 |

本地基线已经存在标准局跟花校验；未复现“仍持有首攻色数字牌却成功提交其他颜色数字牌”。本次明确给跟花函数传入牌库类型，统一真人提交、合法牌视图、机器人和超时的规则入口，并修正单色仍提示跟色的问题。现在提示区区分“须跟色”“缺色可任意出牌”和“单色不跟花色”。不合法的牌仍可预览，确认按钮拒绝提交。

线上版本的只读 HTTP 请求被当前访问路径返回 403，不能据此判断生产代码是否存在同一问题。本次交付以本地复现、独立断言和 PR 为依据，不将新增回归描述为已经定位并修复了一个已证实的线上根因。

## 牌桌整理

- 默认只突出轮次、主牌、当前行动、玩家身份及预测／实赢，本人另保留总分。累计赢墩、猜中轮数和胜局收进计分表，删除主画面的重复提示。
- 普通手牌去掉外框和背景，贴桌面扇形排列，按实际剩余张数收拢；手机仍可滑动、预览、展开、排序和确认。空手牌不保留一块空面板。
- 横屏将个人数据放入左下紧凑区域，与右侧手牌并排；底部工具和出牌按钮按各自内容占位。顶部使用独立悬浮按钮，减少遮挡；三维横屏镜头靠近牌桌以减少桌后空带。
- 横屏墩末优先显示公开牌及继续操作，暂时让出手牌位置，下一墩恢复；轮末详细成绩只在结算时出现。
- 聊天面板放在聊天按钮同一容器中，从按钮上方展开，大厅靠右、牌局按各端实际按钮位置定位。面板保留在应用重绘之外；输入聚焦不主动滚动牌桌，横屏展开时为个人信息和出牌按钮留位。

## 验证边界

`tests/rules-audit.test.js` 使用独立的合法牌、判胜和计分断言，完整跑完 64 种标准组合与 32 种单色组合，覆盖人数、公开／隐藏／秘密预估、加减预估、先见之明、完整／快速局；另测特殊首攻、后出 W、缺色、机器人、超时，以及持久化后联机权威端拒绝违规操作且不改牌局。

`scripts/rules-ui-review.mjs` 仅供本地／手动执行，检查真实按钮能否提交违规牌、1／5／15／20 张手牌的宽度变化、无框样式、聊天按钮与面板相邻及重绘保留输入。继续运行既有布局、触控、六人局与真实本地 Durable Objects 回归。最终结果及截图见 [H-021](dev-memory/HISTORY.md#h-021)。未新增依赖、GitHub 工作流、远端截图矩阵或重复 CI 步骤；浏览器设备模拟不等同于真实手机键盘、GPU 和运营商网络验收。
