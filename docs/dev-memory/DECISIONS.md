## D-001 · 2026-10-20 · 每局投票及五种变体
- 状态：已采用；来源：用户本轮批准的完整实施计划。
- 后续变更：投票频率及先见之明的首轮限制由 [D-006](#d-006) 取代，其余基本判定和隐私要求继续适用。
- 适用范围：规则引擎、玩家视图、机器人、开局与再开局流程。
- 每局第一轮发牌前按类别全员投票，机器人不投票；最高票并列的选项重投，其他结果保留。过程中隐藏票面，席位冻结；离线等待重连，房主可以取消。
- 公开／隐藏／秘密预估三选一；加减预估仅配公开预估，可以叠加先见之明。先见之明仅第一轮隐藏自己并展示其他人的整手牌，预估完恢复正常。
- 单色限 3–4 人；每人一色 1–13 加一巫师一小丑，每轮重洗个人完整牌库，第 1–12 轮发 4–15 张。无主牌，数字跨花色比较，同数先出胜。单色同样允许 5 轮快速局。
- 采用现有房主权威 PeerJS 架构；viewFor 必须过滤未公开手牌、预估和票面，机器人只用自己的可见信息。房主仍持有完整状态。
- 投票会增加开局步骤，连续平票可以持续重投，不增加房主强制裁决或超时默认票。
- 实现入口：src/game.js、规则投票与界面模块；仅在用户改变玩法时重审。

## D-003 · 2026-10-21 · 主牌动画、去环与圆心对齐
- 状态：已采用；补充 D-002 的减少动态效果行为。来源：用户反馈“主牌没有转动啊”，当前内置浏览器实际返回 `prefers-reduced-motion: reduce`。
- 默认仍跟随系统偏好；agent 在本次修复中选择增加「主牌动画：开／关」，使玩家可以主动开启或关闭主牌的旋转与悬浮。
- 用户明确操作后以 `wizard-trump-motion` 保存在本浏览器 localStorage，刷新保留；仅覆盖主牌动画，不修改操作系统设置及其他场景动效。三维和二维遵循同一个开关。
- 入口：主页／大厅工具栏、对局菜单；首次未选择时继续响应系统减少动态效果的变化。需要恢复自动跟随的界面时再扩展，目前保留简单开关。
- 用户随后明确不需要主牌周围的环：移除三维悬浮光环与二维对应装饰，保留卡牌本身的转动和悬浮。主牌花色仍由固定文字和桌面圆纹表示；此项取代 D-002 中悬浮光环的设计。
- 用户反馈视角中主牌偏离圆心：取消普通对局与主页的向桌后偏移，卡牌的桌面坐标改为 `(x=0, z=0)`，位于实体圆心正上方。悬浮高度保留，因此牌面投影仍高于桌面圆心；先见之明阶段继续采用避让公开手牌的特殊位置。二维／固定文字默认锚点由视口高度 33% 下移至 37%；本墩出牌从 `z=1` 前移到 `z=1.4`，为旋转中的主牌留出间距。

## D-005 · 2026-10-21 · 公开房间发现与只读观战
- 状态：观战隐私约束继续采用；仅列出开局房间的范围已由 [D-017](#d-017) 扩展。来源：用户要求列出正在对局的房间并可进入观战，明确选择「只看公开信息」。
- 观众不占 3–6 人玩家席位，不投票、出牌、改名或发送聊天；所有未出手牌均不下发，先见之明也不例外。秘密与尚未揭晓的预估、票面遵循公开时机。允许查看公开聊天及最多 100 条公开操作记录。
- agent 选择沿用房主权威 PeerJS 架构，独立记录观众连接和只读握手角色，并由房主拒绝观众伪造的玩家操作。会话刷新恢复按 spectator 角色重新连接，缓存和实时视图都经过公开字段白名单。
- 联机房间开局后自动公开摘要；大厅、投票、单人练习和终局不进入目录。目录只转发房间码、房主显示名、人数、轮次、阶段和观众数，不转发手牌、聊天或身份令牌。最多 50 间活跃房间，每房最多 50 名观众。
- 发现仍是点对点估算，网络限制或协调者换届可使目录暂不可用；不能保证覆盖旧版本、离线或受限网络房间。namespace 升为 v2，避免旧版只统计人数的协调者永久吞掉房间广告；过渡期人数按同版本统计。
- 入口：src/presence.js、src/room-directory.js、src/spectator-events.js、src/main.js 和 spectatorView。若用户改变观战信息范围或转向权威目录服务器，再重审。

## D-006 · 2026-10-21 · 固定牌库与局长、逐轮选择变体
- 状态：已被 [D-013](#d-013) 的房主开局前选定整局规则取代；来源：用户明确更正为“每一轮前都可以决定变体，不是一整把”，并确认“牌库和局长开局确定；预估方式、加减预估、先见之明每轮选择”。

- 轮末先结算，房主发起下一轮投票；各类别仍最高票获选、平票项重投。投票结果仅在房主确认发牌时成为当前规则，同时轮换庄家、推进轮次。后续轮取消投票回上轮结算，不能增删座位或丢失成绩／历史／聊天。

- 已开始的旧局继续当前轮，从下一轮起进入投票；旧的首轮投票快照仍可继续。不在一轮中途改变已采用规则或重发牌。rulesVersion=2 标记本次行为：旧存档第二轮起沿用的 foresight=true 仅代表首轮曾开启，恢复时置 false，避免突然隐藏此前已看过的手牌；新版本保留当轮选择。访客只恢复原玩家视图，不自行迁移规则。
- 取代 D-001 的每局投票频率与先见之明首轮限制，并更新 D-004 中快照隐私所适用的轮次。实现入口：src/game.js、src/rules-vote.js、src/room-session.js、src/rule-ui.js、src/main.js。
