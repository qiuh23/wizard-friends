- Node 初始化发现已经到期的房间后，在接受新连接前持久化关闭并清除游戏私密数据，取消 alarm；永久关闭标记保留。Worker 同一控制器在 alarm／后续持久化中保留同样的关闭和清理规则。

进程崩溃期间最后一条实际心跳时刻无法从已丢失的内存重建。采用 `savedAt` 是保守边界，可能比真正断线稍早；在线房现有三十秒检查点继续保留。没有 `savedAt` 的历史记录只能在首次恢复用当前时刻补齐，不能声称能重建未知历史。未来时间戳被限制在当前时刻，不从错误未来记录授予额外期限。

## 保留的房间与续赛语义

| 状态 | 沿用的规则 |
| --- | --- |
| 普通真人房 | 房主最后一个有效连接离线后 30 分钟；保留期内返回恢复原身份并取消普通离线计时 |
| 房主主动暂停 | 同次暂停首次离线后固定最多四小时，再次短暂重连不延后；正式恢复后下一次暂停另起周期 |
| 房主在线 | 不因普通闲置关闭；暂停房在线期间也不改变既有行为，再次离线沿用本次暂停固定截止 |
| 个人练习 | 浏览器本地保存，离开十分钟到期；暂停不延长，不是 Node／Worker 的联机房 |
| 到期续赛 | 房主仍不在、有在线真人且本轮进行中，向到期时在线真人发起六十秒投票；机器人／观众不投票。任一拒绝或未全员确认则关闭 |
| 一致同意后 | 只完成当前轮，离线席位沿用现有临时代打；结果由在线真人确认，或六十秒展示上限到期后关闭。房主回来不撤销投票或收尾标记 |
| 关闭与隐私 | 永久 tombstone 阻止旧链接重建；清理牌局、手牌、身份映射、请求历史等，独立安全审计仍按原保留机制处理 |

其他玩家聊天、机器人动作、公开列表刷新均不续期。Node 复用生产 Worker 的 `RoomRelay`／`RoomAuthority`，没有另外写一套期限或引入新的续赛规则。
