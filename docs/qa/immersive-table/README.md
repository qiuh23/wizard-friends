## 实现

- 聊天、暂停、记分、菜单、排序、展开/收起使用同一 24px SVG 网格，入口保留短标签、完整可访问名称和 44px 触摸区域。聊天未读角标、已有气泡、草稿及键盘处理保留，面板仍为持久节点。
- 玩家保留「赢 / 估」和数字；秘密预测用锁形及「未公开」可访问说明。主牌使用花色 SVG 加短标签，仍可打开原卡。领先和赢墩区分，轮末得分显示命中/未中与带正负号数字，详细计算、逐轮成绩及胜负理由放在记分/菜单。
- 确认出牌独立显示；禁出原因在个人行动区直接可见，替换重复提示并完整换行，W/J 例外不被截断。移除会挡住公开牌/头像的重复选中预览；选中手牌高亮及确认按钮的完整可访问说明保留。
- 竖屏展开手牌时，沿用已有紧凑座位/公共牌布局，将身份放在上方并预留个人提示和确认区域。收起恢复原牌位。横屏展开区避让右侧操作，桌面也支持隐藏/显示手牌。
- 普通轮末移除结算框及 `next` 按钮。Node/Worker 共用的 `RoomAuthority` 在已有 `collection.at` 到期后自动发下一轮；练习使用同一 3 秒收牌期限。暂停保存余量，断线等待全员回来，聊天/刷新不重置期限。终局不自动重开，到期续赛仍只完成当前轮并要求确认离开。
- 终局用明确列宽和统一对齐规则，名次居中、玩家左对齐、数字右对齐；缩短表头，保留完整含义。横屏给排名表更多宽度，小屏可横向/纵向滚动到全部玩家与总分。解散仍在已有菜单中。
