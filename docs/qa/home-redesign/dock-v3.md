# 巫师牌首页横排坞与独立加入弹窗

2026-11-15。基线：当前 main `1e0b6e84471e4af0fb8dfbb63f9771de28250ec7`，即已获用户认可方向的 #56。按当前指令 v3 继续修改，不回退 #56。

## 范围与实现

- 首页顶栏覆盖在场景上，保留 #56 左上返回箭头、品牌、规则和设置。首页占满动态视口，手机竖屏场景声明高度为 `100dvh - 200px`；不再以 420px 封顶。在 568–932px 高度，场景容器为视口的 65%–79%。这只是 CSS 声明预算，不是实际像素测量。
- 昵称在按钮上方压成一行；国内随机昵称按钮、海外输入保持原功能。底部三个格按钮依次创建、加入、练习，图标在文字上方。创建沿用金色和实体下沿，其余沿用原次级表面；删除旧 `.menu-choice` 横条和内嵌表单样式。
- 加入表单移至既有 `ModalFrame`，提供房间码、加入按钮与局部状态消息。遮罩、右上角、Esc 关闭，Tab 循环，普通关闭回到加入入口；连接中关闭回到可取消的首页动作。反复开关保持草稿，连接中重复提交不新建连接，取消按钮按节点绑定一次。
- 弹窗打开时关闭设置/规则，规则打开时关闭加入弹窗；有效房间快照后清除首页弹窗状态，返回首页不会自动遮住恢复入口。空昵称提交回到昵称输入；格式/跨站验证和传输仍由原 launch 流程处理。服务器错误在弹窗内可读。
- 恢复链接和默认收起在线房间行保留 #56 结构。候场、对局、结算、返回大厅确认/保存/暂离/跳转函数、规则、服务器、网络协议、素材、灯光、主牌、字体及主题 token 均未改。
