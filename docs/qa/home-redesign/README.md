# 巫师牌首页与返回大厅

2026-11-15。基线：已上线回退 PR #55 / main `2c8a3d2360e243298228fc09397ed9e349d990c4`，其 tree 与 #53 `289e85e` 完全相同。用户详细指令 v2 取代先前首页对齐和返回大厅方案。本 PR 只实施第二部分。

## 界面改前 / 改后

| 界面 | 改前 | 改后 |
| --- | --- | --- |
| 国内 / 海外首页 | 场景、线路文字条、大标题、昵称和多组大按钮纵向排列 | 顶栏集中箭头、品牌、线路小字及图标；烛光三张牌作背景舞台，底部一个紧凑动作区 |
| 昵称与主入口 | 恢复入口可插入创建、加入、练习之间 | 昵称行保留国内随机固定 / 海外输入差异；创建 primary、加入、单人练习固定顺序 |
| 加入展开 | 原地房间码表单，但旧首页很长 | 保留原地展开 / 收起、草稿和提交行为；按钮、昵称与展开表单采用紧凑竖屏间距 |
| 有恢复项的首页 | 返回房间、恢复练习与主入口同尺寸 | 三个主入口之后的一行小字按钮，保留全部恢复项；多项可横向浏览 |
| 在线信息 | 在线人数及完整房间列表常驻 | 默认收起的一行“在线房间 · N”及在线人数，展开显示原目录，不改刷新 / 加入 / 观战逻辑 |
| 首页辅助控件 | 底部规则 / 设置 / 隐私文字 | 规则、设置收至顶栏；海外隐私 / 举报保留在设置内 |
| 候场 | 房间标题旁返回图标，加上设置中的整宽返回按钮 | 只保留统一左上箭头；房间标题首行让出箭头位置，座位 / 规则页 / 底部开始和退出操作不改 |
| 对局 / 轮末 / 终局 | 设置菜单里的整宽返回按钮 | 只保留相同左上箭头；既有轮 / 墩状态 chrome 让出图标位置，不改牌桌、手牌、座位、结算组件 |
| 房间内返回 | 浏览器原生确认框 | 共用现有规则弹窗的 modal shell，显示现有保留说明和原链接返回说明；确认仍先保存和暂离，再跳现有大厅 URL；取消不离开 |
| 退出房间 | 原按钮与原生确认 / 暂离行为 | 原样保留，与返回大厅独立 |

## 不改的范围

- 3D 场景、三张示例牌、卡面 / 模型 / 字体资产、全部原光照、色彩 token、深青毡面、金色和主牌展示不改。标题原显示字体和阴影保留，只调整顶栏字号及位置。
- `src/ui/table.tsx`、`src/ui/settlement.tsx`、候场内部布局和全部游戏 / 网络 / 权威 / 协议模块不改。
- chrome 只有箭头所需的让位：轮 / 墩状态横移；小于 360px 竖屏工具间隙和数字外边距收紧，不改变控件大小或功能。
- 不修改其他仓库或部署设置。
