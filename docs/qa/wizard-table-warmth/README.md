# 左侧暖光、水晶球与向内烛台

2026-11-12，基于已合并 PR #42 的 main `4921f20`。本轮先完成本地修改和检查，随后按用户明确授权提交草稿 PR 评审；不合并、不部署。已查看用户附图作为问题参考，不将附图当作本轮运行结果。

## 实现

- 水晶球保留原 GLB 外壳及底座，增加低面数不透明蓝色内球，让轮廓不再只靠透明壳和二维亮点支撑，减少底座穿透造成的空心感。外壳稍提高不透明度并加入微弱蓝色自发光，仍无透射额外通道。亮点缩小并随相机保持在实体内球之前、玻璃壳内，避免内球挡住亮点；球心随原微弱呼吸。
- 原右侧提灯搬到左侧次要蜡烛旁，保留金属灯体。玻璃改为暖色半透明，灯内加入蓝光纹理之外独立的暖白核心；不只是把光源搬家。手机继续隐藏提灯实体，避免挤占操作空间。
- 新增 `wizard-warmth.mjs`：两片低透明度琥珀色桌面反射光池，左侧更强并向桌内偏移；手机保留柔和局部暖色。两片光池和提灯核心共用一张64×64 RGBA纹理，约16KiB，无额外下载。光池在Y=.3555，高于桌毡、低于Y=.382牌面，保持深度测试，不覆盖牌面/UI。
- 桌面主蜡烛从X=-5.25/+5.15移至-4.65/+4.60；次要蜡烛略内移并错开纵深。手机从安全区宽度的3.5%/96.5%移到7.5%/92.5%，沿用完整模型投影、刘海安全区、HUD及手牌操作带回收逻辑。
- 暖色点光范围适度扩展，环境光和曝光保持原值，不整体洗亮暗色牌桌。桌面仍最多4点光、手机/紧凑/低功耗最多2点光，无新增阴影、bloom、RAF或动画循环。
- 球内球、暖光核心、共享纹理和材质有幂等释放路径，恢复原缓存材质与透明排序。
