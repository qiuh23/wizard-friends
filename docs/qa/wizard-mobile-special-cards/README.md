# 手机牌桌与特殊牌小人

2026-11-12，基于 main `aaaf453`（已合并 #41）。本次是用户手机横屏截图的后续优化，原水晶球、16件GLB与已合并修改保留。草稿评审，不合并或部署。

## 实现

- 预测按钮从拉满宽度的椭圆改为44×44圆角方格，面板按内容收紧、最多466px；长局仍可横滚，高屏可双排。方向键/Home/End跳过禁用值；预测规则与按钮动作不变。
- 领先与赢墩采用青白描边、暗蓝衬底、文字及不同符号，避免黄牌上金标不清。WebGL实体牌采用青边＋深色外沿，二维使用相同色系。当前领先依旧来自原 `winner()`。
- 紧凑横屏蜡烛标定宽从14px再乘0.65（约9.1px）改为24px；竖屏21px，其他小屏22px。取消二次缩小；紧凑照明增加局部暖光和少量冷色填光。小屏仍最多2点光，无点光阴影、bloom或额外渲染通道。
- 巫师与小丑是程序化制作的真实低模小人：尖帽、胡须、法杖与三角帽、铃铛、双色服装。每只合并成1个顶点色网格，巫师616、小丑1104三角；每桌只缓存两套几何，实例材质独立。没有新增下载、纹理、灯光或骨骼蒙皮。
- 新特殊牌落桌后，小人从原牌中心跃到该牌上缘桌毡。复用原 `TableMotion` 时钟，270ms开始、1120ms落定，小丑转一圈；停住后无额外待机动画。收牌初段缩回，跟随原结算截止，不延迟下一墩。卡牌本身仍按原方式移动。
- 首次载入、重连、旧事件直接显示已落定小人；聊天、排序、窗口重绘不重新启动。暂停冻结。系统减少动态效果下直接落定，并永久结束本次入场，来回切换偏好也不重播。WebGL不可用时继续原可读二维牌，不伪造3D。
- 不改游戏规则、AI、联机协议、隐藏信息、国内/海外策略或发布流程。

## 尚未通过的验收

本环境 `/usr/bin/chromium` 在页面建立前报 `socket() failed: Operation not permitted`。普通启动与获准升级权限后同样失败。因此没有浏览器截图、真实GPU数据、手机帧率或最终布局验收。不能据CPU测试宣称可直接上线。

```sh
npm run dev
GAME_URL=http://127.0.0.1:5173/ BROWSER_EXECUTABLE=/usr/bin/chromium node scripts/wizard-mobile-review.mjs
```

该脚本通过仅本地响应替换暴露检查钩子，覆盖844×390、667×275、1024×460、390×844、1280×800，3/6人，44px预测格、短预测面板、领先徽标、小人落地及反复质量切换。测试钩子不进入生产源码。脚本使用合成练习状态，不代替完整真实对局。

合并前仍须实际检查：6人最矮横屏的小人是否靠近头像/相邻牌、牌下姓名与徽标是否碰手牌，数字超过一行时的滑动和键盘可达，蜡烛实际亮度与安全区，连续特殊牌、暂停/后台/重连、收牌及2D回退。当前小人尺寸与落点是实现选择，须用户视觉复核。
