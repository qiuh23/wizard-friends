# 手机竖版首页牌桌复用对局场景

基线：main `e0acf2497b2c144ceb3cb1a13ad6c454d0adb840`（#58）。

用户要求：首页在手机竖版时使用手机竖版对局中的桌面，仍保留现有三张牌和一张旋转牌。没有新增参考图。

## 实现范围

- 仅首页且视口 `max-width:700px` / `orientation:portrait` 时复用对局的 58° 相机、桌面外围、边缘道具摆位与 portrait 灯光。保持实际逻辑模式为 hero，避免把首页当成游戏。
- 相机与灯光增加可选 portrait 参数，未传参数时仍从原画布比例判断，对局默认行为不变。首页画布比视口短 200px，短竖屏仍明确走竖版分支。
- 两张平放样牌的世界坐标、旋转与材质不变。中央巫师牌仅竖版改为 scale 1.2、中心 y 1.5、z 1.6，仍使用原旋转、上下浮动、暂停和减少动态机制。直接照搬原 hero 坐标会使 320×568 上转动牌顶边投影到约 −4px；新坐标让完整牌面避开顶栏并离开毡面。
- 顶栏、按钮、昵称、目录、加入弹窗、CSS、素材、配色 token、桌面/横屏首页、候场页、规则和协议均未改。仅手机首页使用已有对局灯光，不新增光源或美术资源。
- 同尺寸重复 attach 会重新应用竖版外围可见性与圆环透明度，避免目录刷新恢复成 hero 状态。

## 验证

- `npm run check`：语法和 TypeScript 通过。
- `npm test`：470/470 通过。
- `SITE_EDITION=cn npm run build` 与 `SITE_EDITION=global npm run build`：通过；保留既有大 chunk 提示。
- `npm run worker:check`：使用本地可写 XDG_CONFIG_HOME 后通过。初次失败仅为默认配置目录不存在；未更改远端配置。
- `git diff --check`：通过。
- 真实 Three.js 相机矩阵与对局 framing 对齐；尺寸含 320×480、320×568、360×640、390×568、390×844、430×932、600×700、700×701。
- 三张真实 mesh 的角点覆盖 128 个旋转角度和三档浮动，横向边距至少 8px，投影保持在 64px 顶栏下方 8px 与画布底部上方 12px 之间；浮牌最低点高于 y=.36 毡面。另测横竖切换、同尺寸重挂载、减少动态、原桌面/候场/对局矩阵。
- 真实 GLB 几何/层级解析测试覆盖窄屏道具边界、高低画质往返及与对局道具位置的一致性；首页无 `.table` 祖先时不调用 `getComputedStyle(null)`。

Chromium 在托管云的进程启动阶段因 `process_singleton_posix` 的 `socket() failed: Operation not permitted` 终止，页面未加载。受限命令与申请扩大命令环境的启动尝试均出现同一 OS 限制，没有审批拒绝。没有截图、真实 WebGL 像素或真机触控验收；上述几何测试不等同于浏览器或手机截图。发布后记录精确版本、常规 CI 与双站健康/WebSocket 证据于私有交付页。
