# 角色更清楚、落在牌面与局部烛光调整

2026-11-12，基于已合并PR #42的main `4921f20`。本轮先按用户要求完成本地修改及验证，随后获得提交PR的明确授权；以草稿PR评审，不合并、不部署。用户附图仅作参考，不是本轮运行结果。

## 角色

- 先前角色采用较暗桌面光照下的标准材质，只有很弱的统一自发光。现在使用内置不受灯光影响的顶点色材质，并在顶点色里按模型法线保留柔和明暗，避免暗处变黑，同时保留真实立体轮廓。没有自定义shader、加灯、bloom或改变整个牌桌曝光。
- 提亮蓝紫/青粉衣服、面部和金色细节，角色缩放从0.55改到0.8，约增大45%。巫师帽檐略收窄、脸和眼睛稍前移，俯视角更容易看清面部；角标仍在模型横向轮廓之外。
- 小人现在是对应实体牌的子节点，从牌面插画中心弹出，落在同一牌面中央略靠前处（本地Z=0.10），脚底贴近卡面。随卡牌入场、领先强调和收牌一起移动，不再跳到牌外桌毡。
- 原1120ms入场时钟、暂停、刷新/重连不重播、减动直接落定和原收牌截止保持。每只仍一个网格，巫师616、小丑1104三角，2套缓存几何，无新纹理或模型下载。

## 桌面照明

左侧暖色符文提灯/反射光池、实体蓝色球心、烛台向内调整见[专项说明](../wizard-table-warmth/README.md)。

独立复核发现新不透明球心会挡住旧中心平面上的亮点，已把亮点缩小并放到朝向相机、球心之前且玻璃壳以内的位置；保留深度测试，不靠穿模的置顶光斑解决。球心自发光也跟随原微弱呼吸时钟，暂停与减动逻辑保持。
